3. Description du service

Tête Rouge est un agent IA personnel fonctionnant sur l'appareil de l'utilisateur (tablette, téléphone ou ordinateur). Il propose :

  • Transcription audio multilingue en local
  • Recherche documentaire par intelligence artificielle (RAG)
  • Automatisation de tâches YouTube (téléchargement, upload, génération de script)
  • Outils de cybersécurité défensive (hash, chiffrement, analyse de fichiers)
  • Génération de texte via API tierce (Groq, DeepSeek, etc.)
